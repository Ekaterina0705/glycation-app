# Мини-апп «Гликация»

Telegram Mini App: дневник питания с оценкой гликационной нагрузки.
Семейный режим — переключение между профилями, дневной вердикт, калории,
список приёмов пищи, разбор по темам здоровья и недельный тренд.

- `index.html` — интерфейс, один файл, подключён Telegram WebApp SDK.
- `data.json` — данные приложения.

Статус: кликабельный прототип. Добавление блюда работает в демо-режиме,
разделы нижнего меню — заглушки. Данные приходят из `data.json`.

Опубликовано через GitHub Pages, открывается по кнопке в боте @my_mini_ap_bot.
